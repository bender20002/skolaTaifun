ШКОЛА · СТАТУС КАРКАСА
Размещение онлайн, общий Яндекс.Диск, права редактирования, установка на телефоны
==================================================================================
Все сервисы работают в России без VPN: GitHub Pages (хостинг) и Яндекс.Диск
(общие данные и файлы). Итог: ссылка, по которой все ВИДЯТ модель, а менять
статусы и загружать файлы может ТОЛЬКО тот, кто вошёл паролем редактора.

Порядок: сначала ШАГ 1 (общий Диск), затем ШАГ 2 (публикация ссылки).

────────────────────────────────────────────────────────────────────
ШАГ 1. ОБЩИЙ ЯНДЕКС.ДИСК И ПАРОЛЬ РЕДАКТОРА (≈15 минут, делает админ)
────────────────────────────────────────────────────────────────────
Смысл: на корпоративном Диске создаётся папка, куда складываются статусы,
даты, акты, журнал и все фото/сканы. Право ЗАПИСИ защищено паролем
редактора; посторонний без пароля физически не сможет ничего изменить.

1) Служебный аккаунт и токен.
   • Возьмите отдельный служебный Яндекс-аккаунт компании (не личный:
     токен даёт доступ ко всему Диску этого аккаунта). Подойдёт аккаунт
     Yandex 360 — тогда папка будет на корпоративном Диске.
   • Войдя под ним, откройте:  https://yandex.ru/dev/disk/poligon/
   • Нажмите «Получить OAuth-токен» → «Разрешить». Скопируйте длинную
     строку токена (начинается на y0_...). Никому её не показывайте.

2) Первое открытие приложения для настройки.
   • Сначала выполните ШАГ 2 (опубликуйте папку на GitHub Pages) —
     без этого встроенное шифрование не работает (нужен https, а не файл
     с диска). Затем откройте полученную ссылку в браузере на компьютере.
   • Раздел «Доступ и журнал» → кнопка «⚙ Настройка Диска (для
     администратора)».
   • Вставьте токен из п.1; придумайте ПАРОЛЬ РЕДАКТОРА (его будут вводить
     прорабы); папку оставьте как есть (disk:/ШколаСтатус) либо укажите
     свою. Нажмите «Сформировать конфигурацию».
   • Приложение само создаст папку, откроет её на просмотр по ссылке и
     зашифрует токен вашим паролем. Появится готовая строка
     window.YADISK = {...}. Нажмите «Скопировать».

3) Вставьте строку в приложение.
   • Откройте файл index.html Блокнотом. В самом верху найдите строку
        window.YADISK = null;
     и замените её на скопированную строку. Сохраните файл.
   • Заново загрузите обновлённый index.html на хостинг (ШАГ 2, обновление).

Готово. Теперь у всей команды общие статусы, даты, акты, журнал и файлы.
Пароль редактора сообщите только допущенным сотрудникам. Пароль и токен
в открытом виде на сервере НЕ хранятся: лежит лишь зашифрованный токен,
бесполезный без пароля.

────────────────────────────────────────────────────────────────────
ШАГ 2. ПУБЛИКАЦИЯ ПРИЛОЖЕНИЯ НА GITHUB PAGES (бесплатно, ≈10 минут)
────────────────────────────────────────────────────────────────────
1) Зайдите на https://github.com → Sign up (почта, пароль, имя).
2) Вверху справа «+» → New repository → имя: shkola → Public →
   Create repository.
3) На странице пустого репозитория — ссылка «uploading an existing file».
   Перетащите ВСЕ файлы из этой папки:
     index.html, shkola-model.glb, manifest.webmanifest, sw.js,
     favicon.png, icon-180.png, icon-192.png, icon-512.png
   Нажмите зелёную «Commit changes». Дождитесь загрузки (модель ~22 МБ).
4) Вкладка Settings → раздел Pages (слева) → Branch: main, папка «/ (root)»
   → Save.
5) Через 1–2 минуты вверху страницы Pages появится ссылка вида
     https://ВАШ_ЛОГИН.github.io/shkola/
   Это и есть адрес приложения — раздайте команде.

Обновление приложения (например, после ШАГа 1): в репозитории
«Add file → Upload files» → перетащите новый index.html → Commit changes.
Через минуту ссылка покажет обновлённую версию (в приложении может
понадобиться обновить страницу).

Если у компании есть свой сайт/хостинг — можно вместо GitHub просто
загрузить все файлы папки в отдельную директорию сайта.

────────────────────────────────────────────────────────────────────
КАК ПОЛЬЗУЮТСЯ СОТРУДНИКИ
────────────────────────────────────────────────────────────────────
• Любой, кто открыл ссылку, сразу видит модель и всю информацию
  (режим «только просмотр»). Модель и статусы загружаются сами.
• Прораб/редактор: раздел «Доступ и журнал» → «Войти как редактор» →
  вводит пароль редактора. После этого может менять статусы, объединять
  элементы в группы, вводить даты и акты, загружать фото и сканы —
  всё сразу уходит на общий Диск и появляется у остальных (обновление
  каждые ~10 секунд). «Выйти из режима редактора» — вернуться к просмотру.
• Посторонний без пароля изменить ничего не может — ни через интерфейс,
  ни в обход: ключа на запись у него нет.

────────────────────────────────────────────────────────────────────
УСТАНОВКА КАК ПРИЛОЖЕНИЕ НА ТЕЛЕФОН/ПЛАНШЕТ
────────────────────────────────────────────────────────────────────
iPhone / iPad: откройте ссылку в Safari → «Поделиться» → «На экран
  “Домой”». Появится иконка (ваш рендер школы), запуск на весь экран.
Android: откройте ссылку в Chrome → меню ⋮ → «Установить приложение»
  (или «Добавить на главный экран»).

────────────────────────────────────────────────────────────────────
ГДЕ ЧТО ЛЕЖИТ НА ДИСКЕ
────────────────────────────────────────────────────────────────────
Папка «ШколаСтатус» на служебном Диске:
  • <модель>.json — общее состояние объекта (статусы, даты, акты, журнал);
  • подпапка «файлы» — все загруженные фото и сканы документов.
Это одновременно ваш резервный архив исполнительной документации.

────────────────────────────────────────────────────────────────────
НЕСКОЛЬКО ОБЪЕКТОВ / ДРУГИЕ КОМПАНИИ
────────────────────────────────────────────────────────────────────
• Каждая модель (.glb) автоматически ведёт свой файл состояния в папке —
  можно вести несколько объектов на одном Диске и одной ссылке.
• Для другой компании — свой служебный Яндекс-аккаунт и своя копия папки
  с приложением (данные полностью изолированы).

────────────────────────────────────────────────────────────────────
О БЕЗОПАСНОСТИ (честно)
────────────────────────────────────────────────────────────────────
• Право ЗАПИСИ надёжно защищено паролем редактора (токен зашифрован
  алгоритмом AES-GCM, пароль растягивается PBKDF2). Подберите надёжный
  пароль и меняйте его при смене состава бригады (пересоздать настройку —
  тот же экран «Настройка Диска»; при желании смените и токен, обновив
  пароль служебного аккаунта).
• Просмотр открыт всем, у кого есть ссылка (по публичной ссылке папки).
  Если нужно ограничить и просмотр (личный вход каждому сотруднику) —
  это делается через отдельный сервер; скажите, подготовлю.
