Расценки и доступ к аналитике

Стоимость куба складывается из четырёх частей: работа по типу конструкции, бетон, арматура (норма берётся из ваших реестров) и прочие расходы одним процентом — опалубка, расходники, аренда. Так не нужно вести длинный прайс.
Расценки шифруются паролем: без него суммы в рублях посчитать нельзя даже через инструменты разработчика. Объёмы и статусы остаются видны всем по ссылке — это свойство общедоступной ссылки, полностью закрыть их может только серверная версия.
